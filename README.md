This repository contains the source code for the
[Eclectic](https://eclectic.trincoll.edu) blog.

## Project File Layout

### Blog Content

\_posts
: Blog postings in Markdown format

\_pages
: Currently empty

files
: Mainly images used in blog postings

dl
: Files offered for visitors to download

### Blog Infrastructure

Gemfile
: Installs Jekyll static site builder

\_config.yml
: Configuration of the site builder

\_layouts
: HTML templates

\_includes
: Include files for HTML templates

assets
: Images, stylesheets, and scripts which are part of the framework of the
  blog site
